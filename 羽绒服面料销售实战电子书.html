01纤维总览：先分清三种出身，再谈成分

吊牌上写「100% 聚酯纤维」「55% 莱赛尔 45% 棉」，客户看不懂，你要能一句话翻成人话。所有纤维只有三种出身：天然长出来的、天然材料溶解重造的、化工合成的。分清这三类，后面所有成分、手感、价格、洗护，都有了解释的根。

出身包含什么本质与卖点羽绒服里用在哪
① 天然纤维棉、麻（亚麻/汉麻/苎麻）、蚕丝、羊毛、羊绒直接从动植物来的，吸湿亲肤，但强度、抗皱各有短板里布、内搭、拼接领口
② 再生纤维素粘胶、莫代尔、莱赛尔、醋酸、铜氨原料是木浆/棉短绒，溶解后重新纺丝；吸湿比棉好，工艺决定档次内搭、时装款里布
③ 合成纤维涤纶、锦纶、腈纶、氨纶从石油化工来，强度高、尺寸稳、便宜；吸湿差是通病面布、胆布的主力
一句话话术

「羽绒服的面布基本是 ②和③，①多在内搭和里布。」客户问「这是什么料」，先答出身，再答具体品种，比直接报化学名好懂十倍。

必须记住的一条

成分标签上的名称必须按标准写：GB/T 4146.1《纺织品 化学纤维 第1部分：属名》、GB 5296.4《消费品使用说明 第4部分：纺织品和服装》。所以「天丝」要写莱赛尔、「冰丝」得写清楚到底是什么——写成商标名是可以被投诉的。

查证入口：国家标准全文公开系统 openstd.samr.gov.cn，搜标准号即可看全文。

02天然纤维：棉、麻、丝、毛，四种性格

这四种在羽绒服上不是主角，但客户一摸里布问「这是不是棉的」，你答不上来就掉分。每种记三件事：怎么来的、好在哪、坏在哪。

2.1 棉：新疆棉为什么被反复提

品种关键差异
细绒棉（陆地棉）最常见，纤维长约 28 mm；新疆棉 90% 是这一类
长绒棉（海岛棉）比细绒棉长约 8 mm，可纺更细的纱，属不同物种；新疆仅约 10%
木棉纤维太短，做不了衣服，多作填充

加工上有三种常见说法，客户最容易被绕：

  • 精梳棉：梳掉短纤维，只留长的，布面光洁、成本高
  • 丝光棉：浓烧碱处理，纤维截面由腰子形变圆，反光强，有丝一样的光泽
  • 彩棉：天然带棕/绿的棉，纤维偏短、杂质多，仍需退浆精炼，品质一般
能直接用的一句

「棉吸汗、亲肤，但湿了干得慢、容易皱——这也是羽绒服外面基本不用棉、只在里布和内搭用的原因。」

2.2 麻：亚麻、汉麻、苎麻

麻纤维刚硬、透气、挺括，但扎人。历史上是平民衣料，棉花普及后被替代，现在多做夏季面料、混纺或工业用。羽绒服上偶尔见于拼接、装饰织带。

2.3 蚕丝：桑蚕、柞蚕、双宫丝、绢丝

种类特点用在哪
桑蚕丝吃桑叶，色白，品质最好；主产区已转到广西、四川、贵州、云南高档内搭、时装
柞蚕丝吃柞树叶，丝呈黄褐色，需漂白；蓬松、便宜蚕丝被（性价比款）
双宫丝两只蚕同结一茧，丝缠在一起抽不出整根蚕丝被；常被当高档卖
绢丝用断丝、边角料重新纺纱织成低价丝织物

2.4 羊毛与羊绒：一句话分清

羊毛来自绵羊（剪毛），羊绒来自山羊（梳绒）——不是同一种东西，价格差好几倍。澳大利亚供应全球约 40% 的羊毛；中国贡献全球约 80% 的羊绒，主产内蒙和新疆。

  • Cashmere：羊绒，词源是克什米尔地名
  • 马海毛：土耳其安哥拉山羊毛，意为「像蚕丝一样的羊毛」
  • 羊驼毛：中空、轻、保暖，价格高于羊毛
被问「是羊绒还是羊毛」怎么答

先看标签：山羊绒（Cashmere）才是羊绒；只写「羊毛」「绵羊毛」就是羊毛。含绒量低于标准限值的，不能叫羊绒制品。

03再生纤维素：从木浆到莱赛尔，五个名字一种原料

这一类最容易被商家包装：原料都是木浆或棉短绒，区别在用什么溶剂、溶完怎么纺。所以「竹纤维」「天丝」「冰丝」听着天然，其实都在这条线上（冰丝是营销名，标签上必须写清真实成分）。

名称工艺与特点要注意的点
粘胶
Viscose / Rayon		用二硫化碳溶解木浆/棉短绒后纺丝；吸湿比棉高约 50%，手感软生产过程污染大；「竹纤维」多属此类，不是把竹子直接纺成丝
莫代尔
Modal		粘胶的改良版，在锌离子溶液中挤压成型韧性比粘胶好、遇水不易破，适合贴身；档次高于普通粘胶
莱赛尔
Lyocell		用 NMMO 溶剂，溶剂回收率可达 99.7%目前最环保的一类；「天丝」是兰精公司的商标，标签必须写「莱赛尔」
二醋酸
Diacetate		纤维素部分酯化，降低吸水性，有塑料感与蚕丝光泽成本低，用于里布、缎类；香烟滤嘴也是这个材料
三醋酸
Triacetate		酯化度 92% 以上，耐热、垂感好、水洗不易变形高端时装用；百褶效果可以做成永久；色域窄，染色难
铜氨
Cupro		用铜氨溶液溶解棉短绒纺丝不含铜金属，名字骗人；手感滑、垂感好
三个最常见的名字陷阱

天丝 → 莱赛尔（商标 ≠ 成分）
竹纤维 → 多为粘胶（不是天然竹纤维）
铜氨丝 → 不含铜，是再生纤维素
还有两个常被问：牛奶丝不含牛奶；大豆纤维确实含大豆蛋白（和常规化纤不同）。

对客一句话

「这几样本质都是木浆做的，差别在溶剂环不环保、丝细不细。想买环保的认莱赛尔，想买挺括有光泽的看三醋酸。」

依据：GB/T 4146.1《纺织品 化学纤维 第1部分：属名》、GB 5296.4 使用说明；标准原文可在 国家标准全文公开系统 检索。

04化纤代号、喷丝孔数与工艺链：看懂供应商的行话

客户和供应商开口就是「75D 低弹」「20D/24F」「三醋酸」「干法纺丝」。这些不是炫技，是报价单里的基本单位。这一章把代号、孔数、纤维品种和整条工艺链串起来。

4.1 常用纤维代号（报价单和吊牌都会用）

代号中文英文／别称羽绒服上常见于
C棉Cotton里布、口袋里布
T涤纶Polyester / PET面布、里布、胆布
N锦纶（尼龙）Nylon / PA轻薄面布、塔丝隆
R粘胶（人棉）Viscose / Rayon里布、衬布

W羊毛Wool毛呢拼接、领口罗纹
两个容易记混的

「V」在部分工厂写法里指维纶，不是涤纶——看到 V 要问一句「是涤还是维」；「人棉」不是棉，是粘胶纤维（再生纤维素），吸湿好但湿强低。写进合同一律用化学名称，别用代号。

4.2 D、F 与喷丝板孔数：一根丝是怎么来的

三个概念，别混 D（旦）＝9000 m 纱线的克重，越小越细　　F＝一根纱里有多少根单丝
喷丝板孔数决定 F：一个孔出一根单丝，孔数越多，同样 D 数下手感越软
单丝旦数 = D ÷ F　　// 20D/24F ≈ 0.83D，属超细旦

喷丝板的孔要均匀对称排布，所以孔数通常设计成 6 或 12 的倍数，便于排列、也便于在纤维细度和生产成本之间取平衡。

4.3 三醋酸酯（Triacetate）：接近真丝的半合成纤维

它是什么

半合成纤维：以天然木浆（针叶树）为原料，把纤维素与醋酸酐反应生成醋酸纤维素，再溶解、干法纺丝。手感接近真丝，比真丝好打理。

卖点
  • 垂感极佳，裙装、裤装显档次
  • 触感舒适、不贴身、抗皱
  • 快干、耐洗、水洗不易褪色
「二醋酸」和「三醋酸」差在哪

纤维素上有 三个羟基：全部参与酯化＝三醋酸，只部分参与＝二醋酸。三醋酸的酯化度在 92% 以上，耐热性、尺寸稳定性都优于二醋酸；二醋酸遇热易变形。日本三菱是主要供应方。

缺点：只能用分散染料染色，色域窄，深色和鲜艳色难做；染整窗口窄，容易色花。

长丝规格在报价单上常写成 3CS（三醋酸长丝），织前要先整经，染整第一道是退浆、精炼——这三步在工厂排产单上经常单独列行，看到别以为是新工艺。

4.4 一条完整的工艺链（从木浆到成品）

再生纤维素路线（三醋酸／粘胶／天丝同构） 天然木浆 →（化工）纤维制造 → 提纯 → 酯化反应 → 溶解过滤（纺丝液）→ 干法纺丝
→ 长丝加捻 → 整经 → 织造 → 坯布 → 检验
→ 前处理（退浆、精炼）→ 染色（分散染料）→ 后整理 → 成品
为什么销售要懂这条链

客户问「为什么这个颜色要多等 7 天」，你能答「三醋酸只能分散染色，深色要二次套染」；问「为什么这批手感不一样」，你能答「纺丝液黏度或加捻不同」。答得出工序，才像内行。

4.5 孔数越高越好吗：常见孔数与手感

常见孔数单丝粗细（同样 20D 时）手感代价
12、24偏粗挺、耐用、成本低透气差、偏硬
36、48中等均衡，常规款主力—
72、96偏细柔软、细腻强度下降、易勾丝
144 及以上超细旦最软、最蓬松、比表面积大成本高、耐撕差

孔数的作用可以一句话概括：影响手感、调控透气、平衡强度与柔软度。同样标 20D，96 孔和 24 孔是两个价、两种手感。

4.6 FDY 与 DTY：报价单上最常混的两个词

FDY（全拉伸丝）

看强度、沸水收缩率、染色均匀性。好货：高强低伸、尺寸稳定、染色均匀（通常要求 4 级）。做面布、要挺括。

DTY（低弹丝）

看弹性、蓬松度、卷曲收缩率（常见 20%–30%）、网络点是否均匀、含油率（1%–2%）。做里布、弹力款、手感要软。

两个容易踩的坑

① 不同批号缩率不同：同一色号分批拿货，织出来门幅会差，撞色款尤其明显；
② 经纬用不同纱（如经 30D、纬 35D）时，染后收缩不一致，布面易起条——下单前问清经纬配置。

4.7 从石油到一块布：一条链记住所有代号

客户问「这布怎么来的」，你能从石油一路讲到布号，专业感立刻不一样。整条链只有五步：

石油→切片→拉丝→织造→染整
环节产出关键代号
原料切片（块）涤纶切片 → P；锦纶切片 → N
纺丝长丝FDY 全拉伸丝（无网络点）／DTY 低弹丝（带网络点）／ATY 空变丝
规格纱线粗细D 数（旦尼尔，5 的倍数）：15D / 20D / 25D
规格孔数F 数（12 的倍数）：12F / 24F / 36F / 72F / 144F
织造坯布涤塔夫／春亚纺／尼丝纺／塔丝隆
密度成品T 数（每英寸经纬根数）：400T / 480T / 500T
看到「480T／15D 34F」怎么读

密度 480T、纱线 15D、34 孔。D 越小越细、F 越大越软、T 越大越密——三个数字一组，规格就定型了。

一个换算别搞错

T 数是每英寸的根数（1 英寸 ＝ 2.54 cm），不是每厘米。同样标 480T，有的厂按英制、有的按公制报，差 2.54 倍，报价前必须问清。

05纤维与纱线：为什么同样一米布，价格差一倍

羽绒服面布 95% 以上是合成纤维，主力只有两个：锦纶（尼龙）和涤纶。剩下的差别，来自纱线怎么纺、怎么变形、怎么织。

5.1 两种主力纤维，一张表说清

对比项锦纶（尼龙 / PA）涤纶（聚酯 / PET）
手感滑、凉、有糯感偏干涩、挺
光泽亮，需消光处理可控（半光／消光）
耐磨最好，约涤纶 2–3 倍好
吸湿约 4.5%，静电较轻约 0.4%，静电重
耐光差，久晒泛黄强度下降好
价格贵（通常高 30%–80%）便宜
典型用途轻薄高端面布、塔丝隆里布、胆布、性价比面布
一句话对客户

「锦纶轻、滑、耐磨，做轻薄款首选；涤纶挺、便宜、抗晒，做里布和跑量款。同样 380T，锦纶每米贵 5–10 元，但一件衣服只多用 1.5 米，摊到零售价里差不到 20 块——穿着体验差得明显。」

5.2 纱线的四个字母，决定手感

D（旦尼尔 Denier）

9000 米纱线的克重。数字越小纱越细：15D < 20D < 30D < 50D。羽绒服面布主流 20D–40D，里布 50D–75D。

F（单丝根数）

20D/24F 表示总旦数 20、由 24 根单丝组成。同样 20D，F 数越高越柔软，也越容易勾丝。

FDY / DTY / ATY

FDY 全拉伸丝，顺滑挺括；DTY 假捻变形，有弹性、蓬松；ATY 空气变形，棉感哑光——塔丝隆就是它。

消光 / 半光 / 有光

加二氧化钛消光。羽绒服多用半光或消光，有光容易显廉价、显反光。

纱线换算（客户问「多少D」时用得上） D = g / 9000 m　　1 D = 0.9 dtex　　tex = D ÷ 9
单丝旦数 = 总 D ÷ F　　// 20D/24F ≈ 0.83D 单丝，属超细旦，手感软

5.3 成分鉴别：30 秒现场判断

纤维近火反应气味灰烬
锦纶先熔成小球，缓慢燃烧芹菜味／淡淡氨味硬淡黄褐球，捏不碎
涤纶熔融收缩，冒黑烟芳香味（偏甜）硬黑球，捏不碎
棉近火即燃，黄焰烧纸味灰白细软，一捏即散
羊毛／羽绒卷曲，离火易熄烧毛发味黑褐脆灰

燃烧只能定性；定量必须靠溶解法（GB/T 2910 系列）：20% 盐酸溶锦纶不溶涤纶，间甲酚溶涤纶不溶锦纶。要写进合同、要出报告的，送第三方实验室。

5.4 尼龙为什么吸湿：分子结构决定手感

锦纶（尼龙）是聚酰胺，分子链之间靠酰胺键（—CONH—）形成氢键，氢键让分子排列整齐、容易结晶，所以尼龙熔点高、强度好；同时酰胺基是亲水基团，能抓住水分子，这就是尼龙比涤纶吸湿好、静电轻的原因。

两种尼龙的差别 尼龙 6：己内酰胺开环聚合　　尼龙 66：己二胺 ＋ 己二酸缩聚
// 66 的氢键密度更高，熔点与强度略优，染色窗口更窄
对销售的意义

客户问「为什么锦纶摸着比涤纶舒服、还没那么电」，答案就在酰胺基：能吸一点水，静电就散得快。但代价是尼龙遇水后强度会下降、干得慢，做户外款要配拒水整理。

第 5 章必背
  1. 锦纶＝滑、亮、耐磨、怕晒；涤纶＝挺、闷、便宜、抗晒。
  2. D 是粗细（越小越细），F 是根数（越多越软），ATY＝棉感。
  3. 燃烧定性，溶解定量，合同靠报告。

0690 绒 / 95 绒：含绒量与残脂率

6.1 先澄清两个概念

概念一："90 绒"指绒子含量，不是含绒量

GB/T 14272-2021 已取消"含绒量"，统一改为"绒子含量"。

绒子含量 = 朵绒 + 未成熟绒 + 类似绒 + 损伤绒；含绒量 = 绒子含量 + 绒丝含量（绒丝是朵绒上掉落的单丝）。

因此旧标"含绒量 90%"按新标口径大约只能标 绒子含量 80%——市面"以前标 90 绒、现在标 80 绒"的由来，不是羽绒变差了，是计量口径变了。这是销售解释客诉时最有说服力的一句话。

标注规则：绒子含量按 5% 跳档（50、55……85、90、95）。实测 82% 可标 80%（稳妥）或 85%（处于 82.5% 分界时需与检测机构确认考核档位）。

概念二："溶脂含量"——行业内并无此标准指标

按语境通常指下列之一：

① 残脂率（最可能）：羽绒水洗脱脂后残留的油脂量。90 绒与 95 绒完全相同，均为 ≤1.2%——残脂率在标准中不随绒子含量分档。

② 耗氧量：反映好氧微生物与洗涤洁净度，90 与 95 绒均 ≤5.6 mg/100g。

③ 口语误听：若问的是"含绒量"，则 90 绒 = 绒子含量 90%，95 绒 = 绒子含量 95%。

为什么残脂率不能降到 0：羽绒是水禽体表产物，天然带油脂。油脂过低，绒朵脆弱易断、韧性下降、蓬松度受损；油脂过高，清洁度差、易滋生细菌并产生异味。标准把它卡在 ≤1.2% 这个"既要干净又不能太干"的区间（旧标为 ≤1.3%）。

6.5 蓬松度：cm 和 FP 不是一回事

  • 两者不可直接换算，只能说 16.5 cm 大致相当于 600–650 FP 级别

  • 别拿 FP 数字去和国标 cm 比大小，会闹笑话

  • 「越厚越暖」——错。堆到 300 g 以上如果不分格，羽绒会下沉板结，反而出现冷点
  • 「充绒量高就一定暖」——还要看绒子含量和蓬松度，60 g 的 95 绒可能比 90 g 的 80 绒更暖
  • 「防风可以忽略」——同样充绒量，有无防风层体感差 3–5℃；轻薄款配冲锋衣外穿就是这个道理

07从石油到切片：化纤的前半生

客户问「锦纶为什么比涤纶贵一倍」，最硬的回答在源头：两者的单体不同，路线不同，成本自然不同。这一段把石油到切片讲清楚，你就不怕问。

7.1 第一步：把原油「切」成不同馏分

炼厂用的是沸点分离：原油加热后，不同物质在各自沸点先后气化、冷凝，分出汽油、煤油、柴油、重油等。化纤用的不是汽油，而是其中石脑油（naphtha）这一馏分，再往下裂解成乙烯、丙烯、苯等基础化工原料。

主线 原油 → 常减压蒸馏 → 石脑油 → 重整/裂解 → PX（对二甲苯）
// 这条线上的价格新闻，最后都会变成你的面料报价

7.2 涤纶：PX → PTA → PET 切片

PX 氧化得 PTA（精对苯二甲酸），与 MEG（乙二醇） 缩聚，得到 PET 聚酯，冷却切粒就是「切片」。切片再送去纺丝，或去做瓶片、薄膜。

石脑油重整PXPX 价格是聚酯链的风向标
PX 氧化PTAPTA 与 MEG 双原料决定切片价
缩聚PET 切片切片价 → 纺丝成本 → 布价

7.3 锦纶：两条完全不同的路

锦纶 6（PA6）

己内酰胺开环聚合。国内产能大、成本低，羽绒服面布用的细旦锦纶多是这一类。

锦纶 66（PA66）

己二胺 ＋ 己二酸缩聚。氢键密度更高，熔点、强度略优，染色窗口更窄，价格也更高。

为什么锦纶贵

① 单体（己内酰胺/己二酸）比 PTA-MEG 路线贵；② 纺丝温度窗口窄、断头多，损耗高；③ 同样旦数，锦纶的强度与耐磨是涤纶比不了的。所以「锦纶贵一倍」不是厂家黑你，是链条决定的。

切片进厂要先干燥

PET、PA 切片都怕水。含水率超标，纺丝时会水解降解——强度下降、断头、毛丝全来了。所以正规纺丝厂第一道工序是干燥（结晶干燥 + 转鼓干燥），这一步偷不得懒。

08纺丝：把切片拉成一根丝

切片是米粒大的颗粒，丝是几微米的单纤维。中间这一步叫熔融纺丝，全流程七段，每段都决定后面的手感与价格。

工序做什么出问题的表现
① 干燥把切片含水率降到 ppm 级，防止高温水解强度低、断头多、毛丝
② 螺杆挤出加热熔融、混匀、稳定压力熔体不均 → 色差、粗细不匀
③ 计量泵 + 过滤精确计量，滤掉杂质与凝胶杂质 → 断头、僵丝
④ 喷丝板熔体通过微孔挤出成丝，孔数就是 F 数孔堵 → 单丝断裂、毛丝
⑤ 侧吹风冷却均匀冷却固化，决定丝的截面与取向风不匀 → 染色不匀（色差）
⑥ 上油给油剂，抗静电、润滑、集束含油率不对 → 织造断经、起毛
⑦ 卷绕按速度与拉伸倍数收成丝饼卷绕张力不稳 → 退绕断头
一个关键概念：取向度

丝从喷丝板出来时，分子是杂乱的（强度低）；被拉伸后分子沿轴向排列（取向度高，强度上来了）。拉多少、什么时候拉，决定了它是 POY、FDY 还是 DTY——下一章讲。

对客户怎么说

「丝是在厂里从切片拉出来的，不是买现成的。孔数、拉伸倍数这些参数定死了，布的手感就定死了——所以同是 20D，不同厂做出来手感不一样。」

报价单上最常见的三个缩写，本质是同一根丝在不同阶段停手。看懂这一章，你就能判断供应商有没有拿低配当高配卖你。

9.1 复合丝：T400 与 T800 是什么

它们不是单一聚合物，而是两种热收缩率不同的丝复合在一起（常见 PET 与 PTT/PBT 并列复合）。染色或热处理后，两组分收缩不一样，丝自然卷曲起来，形成永久弹力——不靠氨纶也有弹性。

  • T400：弹力温和、手感软，轻薄羽绒服常用
  • T800：回弹更高、更挺，做需要支撑感的款
  • 好处：不含氨纶，不会老化失弹，耐洗、耐热
比价别踩的坑

客户拿DTY 的价格来压你 FDY 的货，是最常见的套路。同样 20D，低弹丝每公斤能便宜一截，但挺括度、尺寸稳定性完全两回事。谈价先确认丝型，别一上来就降价。

13燃烧法与拆布：把一块布拆成四个参数

客户拿来一块竞品布，问「你们有没有一样的」，你要能在十分钟内说出它的材质、丝型、密度、组织。这套动作是最实用的销售技能，比背名词管用。

13.1 第一步：燃烧法分材质

纤维燃烧现象气味灰烬
棉/麻/粘胶靠近即燃，火焰快，离火继续烧烧纸味灰白色细灰，一捏就散
涤纶先缩后熔，冒黑烟刺鼻化学味黑色硬块，捏不碎
锦纶缩成小球，火焰带蓝尖类似芹菜/氨基味棕灰色硬球
羊毛/蚕丝燃烧慢，会自灭烧头发味黑色松脆小球
腈纶熔融燃烧，黑烟多刺鼻黑色硬块
安全与边界

取单根纱、在通风处、用打火机侧面燎一下即可，别烧整块布。燃烧法只能定性——涤锦混纺、加了阻燃剂的布，现象会混，最终以送检为准。

13.2 第二步：拆出丝型

从布边抽出经纬纱，用手指搓、拉：看到间隔小疙瘩是 DTY，平滑无节点是 FDY，蓬松乱圈是 ATY。再数一下单丝根数，就是 F 数（可借放大镜或双管镜）。

13.3 第三步：量密度、看组织

  • 密度：用照布镜/双管镜在1 英寸内数经纬根数，相加即 T 数（行业按英制）
  • 组织：一上一下是平纹；二上一下、三上一下是斜纹；缎纹浮长更长、更亮更软
  • 克重与门幅：称重换算 g/m²，量两边门幅

13.4 第四步：对号入座，别拿低配比高配

最常犯的错

客户说「人家 20D 才卖 X 元」，你一看没问丝型就跟着降。实际人家是 DTY，你的是 FDY——成本差一截，性能也差一截。先问丝型，再谈价，这一句能救回很多毛利。

14一块布要走四个厂：先看清全流程

客户催货时，你说「在染厂排队」没人信；你能说出现在到哪一步、下一步几天，客户才服。先记住四个阶段和它们各自管什么。

阶段厂做什么出什么结果
一纺丝厂切片 → 熔融纺丝 → FDY/DTY/ATY一饼饼的丝（原料）
二坯布厂（织厂）整经 → 穿综 → 织造 → 验布白坯布（还没颜色）
三染厂前处理 → 染色 → 皂洗 → 烘干定型有色布、有初步手感
四后整理厂压光、涂层、覆膜、三防、抗静电等能出货的成品布
为什么要分四段讲

因为每一段的交期、责任、损耗都不一样。客户嫌贵，可能是你在第四段（后整理）花了钱；客户嫌慢，卡点通常在第三段排队。能把成本和时间拆到四段，报价和催货才有说服力。

一句专业开场

「我们不是单纯卖布的，从丝到坯布到染色后整，链条是通的——所以你要的颜色和交期，我能给你盯着。」

15纺丝厂与坯布厂：丝怎么变成白坯

15.1 纺丝厂：你拿到的是「批号」

丝按批号出厂，同一批的收缩率、色光才一致。不同批混用，织出来门幅会差、染出来会有段差——撞色款尤其要同批。收到丝先看批号，再上机。

15.2 坯布厂：三步把丝变成布

工序做什么决定什么
整经把成百上千根经纱按长度、张力平行卷到盘头上经纱张力是否均匀 → 有没有经条、松经
穿综穿筘按组织图把每根经纱穿进综丝和钢筘组织与密度就定死了
织造纬纱往复引入，与经纱交织布面风格、纬密、织疵

行业里经密普遍高于纬密：经纱固定在盘头上，张力稳定；纬纱靠梭子/喷气往复，快了容易出问题，也为了省成本，纬密会低一些。

三种基本组织（客户问「什么组织」就这么答）

平纹：一上一下，最密实、最挺，羽绒服面布主力。
斜纹：二上一下、三上一下，有斜向纹路，更软更垂。
缎纹：浮长最长，最亮最滑，也最容易勾丝。

验布这一步不能省

坯布下机要验：断经、稀密路、霉斑、油污。坯布没验出来，染完就退不回去了——染厂不认坯布带来的疵点。行业常用四分制评分，具体扣分线按客户协议走。

16染整体系：坯布怎么变成你手里的布

染整是面料价格的第二个大头，也是最容易出交期和色差问题的地方。你不需要会开染缸，但要能听懂染厂在说什么。

16.1 一条标准流程

从坯布到成品 坯布检验 → 前处理（退浆／精练／漂白）→ 染色 →（印花）→ 后整理（定型／柔软／三防／涂层／贴膜／轧光）→ 检验 → 打卷包装

16.2 三种染色方式，对应三种订单

方式适合起订量（经验）特点
溢流染色轻薄化纤、大批量300–500 kg／缸张力小、手感好，最常用
卷染小批量、多色几百米起灵活但缸差大
连续轧染大批量纯色数千米起效率高、色差小
为什么小单贵

染缸有最小批量，300 kg 的缸染 100 kg 也要开一次机。小单的染费要按整缸摊，这就是「同样的布，500 米比 3000 米每米贵 2 元」的真实原因，不是供应商坑你。

16.3 后整理：加价项都在这

工艺作用对价格／手感的影响
定型稳定门幅、克重、缩水率必做，计入基础染费
柔软改善手感小幅加价，硅油类会影响三防
轧光／压光压平纱线、缩小孔隙无胆防绒的关键工序
三防拒水、拒油、防污加价明显，见第 18 章
涂层成膜防风防绒中幅加价，手感变硬
贴膜／复合防水透湿加价最大，工序最多
抗静电减少吸附、电击感导电丝嵌织另计
上表的先后，按成膜方式分两条路线

涂层款：定型 → 轧光 → 三防 → 涂层。贴膜／复合款：定型 → 轧光 → 复合 → 三防。两条都把三防压在“正面还是素布”这一步上，只是成膜工序的位置不同。

顺序看工艺，不是一句铁律

涂层款（PU／PA 涂反面）：先三防，后涂层。三防靠浸轧＋焙烘，只能在正面素布上做；涂层厂接的通常是已整理好的基布。
贴膜／复合款：先复合，后做表面三防。复合的高温高压会把拒水层压塌——Columbia 的防水透湿面料专利里写明，DWR 是复合完成后单独施加的一道工序。
印花、绣花、压胶条：一律排在三防之前，它们会污染、磨损或高温破坏拒水层。
唯一不变的一条：三防必须做在正面素布上，后续工序温度不能超过功能层的耐受上限。签约前问工厂三句——三防在前还是后？涂层还是贴膜？焙烘多少度？

第 16 章必背
  1. 前处理 → 染色 → 后整理，三步都可能影响交期。
  2. 小单贵在染缸起定量，不在布本身。
  3. 涂层／贴膜在前，三防在后，顺序错就白做。

17染厂五步与交期：冷堆、进缸、皂洗、定型

这一段是最容易出交期事故的地方。五步走完，快则三五天，慢则两三周——差别全在排队和前处理窗口。

步骤关键内容时间与红线
① 前处理退浆、精炼、开纤（冷堆或汽蒸），把纤维打开，便于上色冷堆 3–5 天，最长不超 7 天
② 检验查断经、霉斑、油污，合格才进缸前处理后 7–15 天内必须染色，超期要重新处理
③ 染色按丝型选缸：平缸适合长丝（离心力小、张力匀）；双管/斜管适合低弹丝（水流带动，避免离心力造成色差）视品种，旺季排队约 1.5 天
④ 皂洗不是普通水洗，是皂洗去浮色，决定色牢度省这一步，客户一洗就掉色
⑤ 烘干定型加助剂（固色、抗静电、柔软），拉幅定型，控门幅与克重定型温度不均 → 色差、手感不匀
交期怎么估（内部口径，供参照）

压光：正常排期约 1 周，不排队纯加工约 18 小时（多机并行）。
防水（三防）：正常约 3 天，实际加工很短，主要耗时在排队。
所以催货要问的是「排在哪个缸、前面还有几缸」，不是「还要几天」。

承诺交期前必须做的一件事

跟生产确认排单，留下书面或聊天记录。延期时这就是你唯一的证据——口头答应的排期，出事没人认。

18三防：客户问得最多，你答得最虚的一块

三防＝拒水（防泼水）、拒油、防污。它是一层后整理助剂，不是涂层、不是膜，所以透气但不挡水压。这一章把指标、话术、失效原因一次讲透。

18.1 原理：把表面能压到水和油之下

为什么会成珠滚落 水的表面张力 72.6 mN/m　｜　油 20–30 mN/m　｜　氟碳链约 15 mN/m
整理后接触角 > 90° → 液滴立起来、滚走，不铺开、不渗透

关键推论：水好防，油难防。无氟整理能把表面张力压到 25–30 mN/m，防得住水，防不住油；要防油必须用含氟。

18.2 三代防水剂：C8 → C6 → 无氟

代际代表性能现状
C8PFOA／PFOS 类拒水拒油最强全球已禁／严格限制
C6短链氟碳，降解产物为 PFHxA拒水拒油好，手感影响小欧盟已限残留（25 ppb）
无氟 C0硅系、蜡系、聚氨酯改性拒水可以，拒油做不到品牌主动切换中
2026 年 10 月起的新变化

欧盟 REACH 附录 XVII 第 79 项自 2026-10-10 起适用于服装鞋类：PFHxA 及其盐 ≤25 ppb、相关物质总和 ≤1000 ppb，按均质材料分层测。注意——限的是残留量，不是禁用含氟。合规的含氟款照样能卖，只是检测成本和批次风险高，很多品牌干脆转无氟。

18.3 四项指标与验收标准

项目标准等级制合格线

市面上九成宣传只报洗前等级，客诉却全出在洗后。签合同要写「洗 10 次后沾水 ≥3 级」，这一句能挡掉大半纠纷。普通助剂耐洗约 10 次，3M 思高洁、Nano-Tex 这类可到 30 次以上。

18.4 三防为什么会失效，怎么复活

四个杀手
  • 柔顺剂：把助剂层糊住，一次就废
  • 高温烘干／熨烫：破坏整理层结构
  • 漂白、长时间浸泡
  • 强碱洗涤剂／反复摩擦
复活办法
  • 洗后低温烘 10 分钟（或隔布低温熨），多数能恢复部分防泼水
  • 仍不行＝整理层已磨损，属正常消耗，不是质量问题
  • 卖点：把这条写进洗标，客诉少一半

18.5 三句话术（背下来直接用）

对客户

①「三防是后整理，不是雨衣——小雨成珠滚掉，持续水压它挡不住，要防水得看静水压。」
②「无氟的防泼水能做到 4 级，但油防不住，这是物理极限，不是偷工减料。」
③「洗完别加柔顺剂、别高温烘，低温烘 10 分钟就能恢复一部分。」

深色面料沾水留痕＝常见客诉

不是质量问题：水成珠滚掉，但蒸发后水里的矿物质留在深色布面。教客户整片湿布擦匀，别只擦那一点。提前说，比事后赔钱便宜。

18.6 防水与透湿：两个数字决定能不能叫「防水」

指标标准怎么读

ISO 811 / GB/T 4744 报的是毫米水柱（mm H₂O）；有些报告用 Pa 或 kPa。换算：1 mm ≈ 9.8 Pa。所以「5000 Pa」只有约 510 mm，是防泼水级别；「5000 mm」才是常见的小雨档。看到 Pa 先换算再比，别被数字唬住。

18.7 C6 与 C8：不是「有氟／无氟」两种，是三代

C8、C6 都是含氟整理剂，区别在碳链长度；现在又多出第三代无氟（C0）。

  • C8：防水防油最强，但 PFOA/PFOS 已被全球限制，基本退出
  • C6：降解产物是 PFHxA，欧盟限残留 25 ppb；PFOS/PFOA 要求做到 <1 μg/m² 级别
  • 无氟 C0：能过欧盟环保要求，防泼水可以，防油做不到
客户说「我们要无氟的」

先确认他能不能接受不防油。很多客户嘴上要无氟，实际要求咖啡、油渍一擦就掉——这两个要求在现有技术下冲突，必须提前说清。

第 18 章必背
  1. 三防＝拒水＋拒油＋防污，是助剂不是涂层。
  2. 沾水 ≥4 级、拒油 ≥4 级、洗后 ≥3 级，三个数字记死。
  3. 无氟能拒水不能拒油；欧盟限的是 PFHxA 残留 25 ppb，不是禁氟。
  4. 柔顺剂是头号杀手，低温烘 10 分钟能救回来。

20.6 两大膜：Gore-Tex 与 eVent 到底差在哪

这两个是客户最常拿来问的。看懂原理，你就不会被「我们的膜更好」这种话绕进去。

Gore-Tex（戈尔，美国）

1969 年 Bob Gore 快速拉伸加热 PTFE，意外得到膨体聚四氟乙烯（ePTFE）。这层膜每平方英寸约 90 亿个微孔，孔径比水蒸气分子大约 700 倍、比水滴小约 2 万倍——所以气体能过、液态水不能过。

三个核心：持久防水、高度防风、卓越透湿。

eVent（美国 BHA，1999 年）

主打「直接透气」：传统膜外面还要压一层 PU 保护层，汗气要先穿过 PU 才能排出；eVent 省掉这层，汗气直出，所以透湿更快，也不容易出现「闷汗」。

卖点是透气与不脱胶。

参数别硬比，方法不同不能直接比

市面上常说「eVent 透湿 5300 g，是 Gore 的两倍」——这个说法要打问号。两家给出的数字往往测法不同（正杯／倒杯、RET、不同温湿度），换算法后差距没有说法那么大。你对外讲，只说「eVent 结构上少一层 PU，透气更快」就够了，不要报倍数。

Schoeller（瑞士）瑞士，软壳专家主打无膜结构：高弹、挡风、耐磨，不靠膜而靠纱线与组织，穿着更软、不闷
对客一句话

  2. 三防是助剂，不是膜；客户混着问，你要分开答。
  3. 谈品牌先谈参数和报告，再谈价格。

21无胆防绒：省掉一层布，多出三道门槛

无胆＝取消独立胆布，羽绒直接充在面料与里布之间，靠面料本体挡住绒丝。这是近五年轻薄款最大的结构变化，也是客户最爱问、最容易翻车的一块。

21.1 为什么要无胆

好处
  • 少一层布，更轻、更软，蓬松感更直接
  • 省一道胆布成本与一道缝制工序
  • 透湿更好，穿起来不闷
  • 可做更细的绗缝格，版型更贴身
代价
  • 面料单价贵 10%–30%（高密＋后整理）
  • 对缝纫要求高：针孔就是漏绒点
  • 洗后防绒可能下降
  • 面料批次差异会被放大（一批漏、一批不漏）

21.2 三条技术路线（价差就在这）

A
高密 ＋ 轧光（压光）把纱线压扁、孔隙挤小，靠物理密度挡绒。成本最低，手感最好；缺点是洗几次后孔隙回弹，防绒性会下降，深色还容易出极光。
B
高密 ＋ 涂层（PU／PA 白胶或透明胶）成膜封孔，防绒稳、还能防风防水；缺点是透气差、手感偏硬，胶层质量差会起泡、发白、折痕裂。
C
高密 ＋ 贴膜（TPU／PU／ePTFE）防水透湿最好，是高端款与户外款的做法；成本最高，对复合工艺要求也最高，膜一脱层整批报废。
一句话对客户

「无胆不是没有胆布，是把胆布做进面料里了。轧光的便宜、手感最好；涂层的防绒更稳、能防风；贴膜的能防水透湿，价格上一个台阶。您这款卖多少钱、洗标怎么写，决定选哪条路。」

  2. 轧光便宜、涂层稳、贴膜贵；价差主要在后整理。
  3. 针孔是最大漏绒源，成衣要按 GB/T 14272 整衣转箱测。

  3. 再生料（GRS）能加价，但要 TC 证书，别口头承诺。

24色号与撞色：颜色对了，单子才稳

撞色款退货的第一原因不是版型，是色差。这一章分两半：前半是把颜色做准，后半是把颜色搭对。

24.1 TCX 与 TPG，别混用

Pantone TCX（布卡）

印在棉布上，染色可直接对标，编号如 19-4052 TCX。报价、打样、确认都用它。

Pantone TPG（纸卡）

印在纸上，光感与布不同，直接拿去染色必偏。设计师爱用，但必须转 TCX 或打样确认。

24.2 ΔE：差多少算差

ΔE肉眼感受判定
≤1.0几乎看不出同色拼接件内控
1.0–2.0并排细看能察觉异色拼接／大货上限
2.0–3.0一眼看出超常规，降级或特价
>3.0明显两个色不合格，返修或拒收

ΔE 是内控惯例，不是国标。合同必须写数字，「颜色基本一致」等于没写。

24.3 撞色怎么搭才不土

四个关系（安全度递减）
  • 同类色：同色相深浅变化——最安全
  • 邻近色：色相环 60° 内，如蓝配绿
  • 对比色：120°，如红配蓝绿
  • 互补色：180°，红配绿——最易翻车
三条实操法则
  • 60-30-10：主 60%、辅 30%、点缀 10%
  • 明度优先：一深一浅比色相差别更重要
  • 三色上限：全身不超过三个色系
安全组合高风险组合
黑＋米白、藏蓝＋姜黄、墨绿＋奶油、灰＋酒红、焦糖＋米大红＋翠绿等面积、荧光色＋高饱和、三种以上高饱和撞在一起

24.4 生产端的四个雷

  • 同缸号：不同缸拼一件必出色差，合同写「同缸交货」
  • 拼接互染：深浅拼接的沾色牢度，内控建议 ≥4 级
  • 缩率差：两种成分缩率不同，洗后拼缝起皱——同成分拼接最稳
  • 同色异谱：D65 下一样，到了商场暖光下变两个色；必须用 TL84／U30 复核
第 24 章必背
  1. 布卡 TCX 能染，纸卡 TPG 不能直接染。
  2. ΔE ≤1.0 同色拼接，≤2.0 异色拼接，写进合同。
  3. 撞色靠明度差，不靠色相狠；比例 60-30-10。
  4. 同缸号＋≥4 级互染，是撞色款的两条命。

开裁前

36.4 全书十二句

背下这十二句，八成场合够用
  1. 锦纶滑亮耐磨，涤纶挺闷便宜；D 看粗细，F 看软硬。
  2. T 是密度，越高越防绒也越硬。
  3. 米重＝克重×门幅；报价一律按有效门幅。
  4. 无胆不是不要胆布，是把胆布做进面料里。
  5. 轧光便宜、涂层稳、贴膜贵，价差在后整理。
  6. 三防是助剂不是涂层：沾水≥4、拒油≥4、洗后≥3。
  7. 无氟能拒水不能拒油，这是物理极限。
  8. 柔顺剂是三防头号杀手，低温烘 10 分钟能救。
  9. 布卡能染、纸卡不能直接染；ΔE≤1.0 才叫同色。
  10. 98 码报 10 元＝足码 10.20 元，比价先折足码。
  11. 用量＝净面积÷(门幅×利用率)，撞色款利用率低 8 个点。
  12. 成本七步走完，底线才不是感觉。
