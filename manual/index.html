一、客户（第一规则）

只服务三类人：一批服装批发老板（自己有档口）、服装设计师、服装设计工作室。

客群在哪拿布干什么每天在想什么
一批批发老板平湖、杭州批发市场，有档口选布 → 做货 → 档口批发 → 返单这版卖不卖得动、成本压不压得住、客户会不会退
服装设计师园区服装公司、版房选布 → 做样衣 → 卖版好不好看、今年什么色好卖、版新不新、打样快不快
服装设计工作室杭州园区、独立工作室自己开发款 → 选布打样 → 把款卖给客户（批发客、品牌）这一版有没有辨识度、布能不能撑起卖价、小单几件能不能做、颜色跟不跟得上

不服务：只收加工费的服装厂、C 端消费者、品牌总部、纯同行。

三条铁律

  1. 只讲他明天能用上的——一个判断、一句话、一个数
  2. 只用他的语言——「这批压手里了」，不是「库存周转率」
  3. 每条必须有他的原话——客户说／老板说／设计师说

出片四问（全过才做）

  1. 是批发老板、设计师或工作室会遇到的场景吗？
  2. 他听完能照做、照说吗？
  3. 开头有他的原话吗？
  4. 他会不会转给同行看？

固定命令

时长靠字数控制，不靠变速——变速会把语气拉平，听起来假。

五、封面与文案

平台封面
抖音／视频号不发封面图，直接发视频（平台自动取首帧）

每天只产出一张封面：小红书 3:4。不导出首帧文件、不做抖音／视频号封面。

封面模板（宋体 Songti SC）

顶部条（栏目／日期）＋ 标题两行 96 ＋ 蓝短横线 ＋ 大关键词 190 ＋ 副标 44 ＋ 要点 44（一条）＋ 品牌条。

不许用带底图的旧模板——会在底图上再叠一层字，出现重影和旧数据（142 门幅、34 克）。

文案三条

  1. 第一行必须是提问句（抖音多数版本没有评论置顶）
  2. 第二行起讲事实与数据，一行一个信息
  3. 三端分开写：抖音（批发老板）、小红书（设计师／工作室）、视频号（老客户）
