从石油到化纤

07从石油到切片：化纤的前半生

客户问「锦纶为什么比涤纶贵一倍」，最硬的回答在源头：两者的单体不同，路线不同，成本自然不同。这一段把石油到切片讲清楚，你就不怕问。

图 7-1　涤纶线：从原油到一块布，九步。蓝框 PX 是这条线的分水岭。
图 7-2　锦纶线：与涤纶同源（都从石脑油来），在「苯」这一步分家。锦纶 66 另有己二腈路线，见 7.3.2。

两条线在「织造、染整」汇合：所以同一家织厂、同一家染厂，可以同时做涤纶和锦纶——但染色工艺完全不同（涤纶用分散染料，锦纶用酸性染料），不能同缸。

7.1 第一步：把原油「切」成不同馏分

炼厂用的是沸点分离：原油加热后，不同物质在各自沸点先后气化、冷凝，分出汽油、煤油、柴油、重油等。化纤用的不是汽油，而是其中石脑油（naphtha）这一馏分，再往下裂解成乙烯、丙烯、苯等基础化工原料。

主线 原油 → 常减压蒸馏 → 石脑油 → 重整/裂解 → PX（对二甲苯）
// 这条线上的价格新闻，最后都会变成你的面料报价

7.2 涤纶：PX → PTA → PET 切片

PX 氧化得 PTA（精对苯二甲酸），与 MEG（乙二醇） 缩聚，得到 PET 聚酯，冷却切粒就是「切片」。切片再送去纺丝，或去做瓶片、薄膜。PTA 为什么老被当成「指标」看、涤纶和锦纶又该怎么分开看，见 7.5。

环节产出影响什么
石脑油重整PXPX 价格是聚酯链的风向标
PX 氧化PTAPTA 与 MEG 双原料决定切片价
缩聚PET 切片切片价 → 纺丝成本 → 布价

7.3 锦纶的前半生：从苯到一根 15D 的丝

锦纶（尼龙）和涤纶最大的不同，是它不是一条线，是两条：锦纶 6 走己内酰胺，锦纶 66 走己二酸＋己二胺。两条路从同一个起点出发——苯，或者石油裂解的丁二烯，但越往后分得越远。轻薄羽绒面料上的细旦锦纶，绝大多数是锦纶 6；66 用在要求更硬、更耐温的地方。

7.3.1 锦纶 6 的前半生：五步到切片

主线 原油 → 石脑油 → 苯 → 加氢 → 环己烷 → 氧化 → 环己酮
→ 肟化 → 环己酮肟 → 贝克曼重排 → 己内酰胺（CPL）
→ 开环聚合 → PA6 切片 → 熔融纺丝 → POY / FDY / DTY → 织造 // 这条线上的每一个价格跳动，最后都会落进你的米价
环节产出这一步在管什么
石脑油重整／抽提纯苯锦纶链的第一成本；纯苯涨，CPL 一定跟
苯加氢环己烷中间体，工艺成熟、利润薄
环己烷氧化环己酮收率与安全是门槛，副产物多
肟化＋贝克曼重排己内酰胺 CPL硫酸/氨耗大；CPL 是锦纶最重要的公开行情
开环聚合PA6 切片黏度（相对黏度 RV）决定可纺性
熔融纺丝POY／FDY／DTY细旦断头多，损耗直接进成本

单耗为公开资料与行业口径的近似值：约 0.75–0.85 t 纯苯 / t CPL，1 t CPL ≈ 1 t PA6 切片（收率 95%–98%），切片到丝再加 1%–3% 损耗。具体以工厂工艺与当期报价为准。

7.3.2 锦纶 66 的前半生：两条腿走路

路线 A 苯 → 环己烷 → 环己醇／酮（KA 油） → 己二酸
路线 B 丁二烯 → 己二腈（ADN） → 加氢 → 己二胺（HMDA）

己二酸与己二胺缩聚，得到 PA66 切片。PA66 比 PA6 难做的关键在己二腈：全球产能长期集中在少数几家（英威达、奥升德、巴斯夫、旭化成等），中国近几年才实现规模化自主（华峰、天辰齐翔等），所以 PA66 的价格波动比 PA6 更“跳”，供应也更集中。

7.3.3 6 和 66，差别到底在哪

维度锦纶 6（PA6）锦纶 66（PA66）
单体己内酰胺（一种）己二酸＋己二胺（两种）
熔点约 220 ℃约 255 ℃
手感更软、更“糯”，适合轻薄更挺、更硬
强度／耐磨好更好
染色窗口宽，好染窗口窄，对色难
价格较低，国产充足较高，受己二腈牵制
羽绒服用在哪15D／20D 面布主流耐磨要求高的款、部分里料

7.3.4 从切片到 15D：为什么细旦这么难

15D34F 的意思是一根复丝 15 旦、由 34 根单丝组成，算下来单丝只有约 0.44 旦。这个尺度上，三件事同时变难：

难点具体表现
断头单丝越细，纺丝张力窗口越窄；断一次就要重新生头，损耗与降等都是成本。
油剂上油不均就出毛丝、染色不匀；细旦比常规旦对油剂更敏感。
织造480T 以上的高密，经纱摩擦大，断经、纬档是常态，机台效率明显下降。
所以「锦纶贵一倍」不是厂家黑你

① 单体路线本身就比 PTA-MEG 贵；② 细旦纺丝断头多、损耗高，做 100 米合格布，实际要投 105 米以上的丝（经验值）；③ 同样旦数，锦纶的强度与耐磨是涤纶比不了的——轻薄款能薄到这个程度，靠的就是它。

7.3.5 行情看什么：三个数就够

看哪个在哪看它代表什么
纯苯生意社、卓创锦纶链的源头成本，最先动
己内酰胺 CPL生意社、CCF锦纶 6 的直接原料，比丝价早 1–2 周
锦纶 POY／FDY生意社、化纤信息网你真正买的东西，报价单就按它谈

顺序是：纯苯 → CPL → 丝 → 坯布 → 染费。客户拿「化纤跌了」压价时，你要能说出他现在说的是哪一段——多数时候他看的是 PTA，而你卖的是 CPL。

切片进厂要先干燥

PA6 切片极易吸水。含水率超标，纺丝时会水解降解——强度下降、断头、毛丝全来了。正规纺丝厂第一道工序是干燥（结晶干燥＋转鼓干燥／连续干燥塔），把含水率压到 0.05% 以下（经验值，随设备与品种变）。这一步偷不得懒，也是判断一家厂是否正规的直观指标。

对客三句（可直接照说）

① 「锦纶看的是己内酰胺和纯苯，不是 PTA——您看的那个数是涤纶的。」
② 「我们这块是锦纶 6、15 旦 34 孔，单丝 0.44 旦，做的是轻薄羽绒那条线。」
③ 「细旦断头多，损耗本来就比常规旦高，这个价不是随口报的。」

7.4 价格是怎么传到布价上的（讲给客户听）

环节看什么价传导到面料大约多久
原油布伦特/WTI1–2 个月（先影响石脑油）
石脑油 / PXPX 加工价差2–4 周
PTA / MEGPTA 现货、MEG 现货1–3 周
切片 / 丝聚酯切片、POY/FDY 报价1–2 周
坯布 → 面料织厂、染厂报价即时传导，看库存

时间差为经验值，行情快时一周就动；具体价格看中国化纤协会与化纤信息网（CCF）公开报价。

客户说「油价跌了，布怎么不降」

答：「油价到布价有传导期，先过 PX、PTA，再到切片和丝，一般 1–2 个月；而且我们买的是已经加工好的丝，短期跟的是丝的报价，不是原油。」——这样答，比「成本没降」有说服力。

7.5 PTA 是什么：一个被当成「指标」看的原料

PTA 不是检测指标，是一种化工原料——精对苯二甲酸（Purified Terephthalic Acid），白色粉末，涤纶链上体量最大的一环。行业里说「PTA 涨了」，说的是它的价格，不是某个检测值。

记三个数 0.855 吨 PTA ＋ 0.335 吨 MEG → 1 吨 PET 切片　｜　PTA 单耗 PX 约 0.655
// 前两个数算切片成本，第三个数算工厂加工费

为什么它被当指标看：PTA 占涤纶成本最大一块，PTA 一动，切片动、丝动、布价一个月内就有反应。做涤纶的人不看它，报不出价。

听到的说法实际指什么怎么用
PTA 盘面 / TA郑商所（CZCE）TA 期货合约，5 吨/手，元/吨最公开的即时价，行业默认参考
PTA 加工费PTA 价 − 0.655 × PX 价工厂赚不赚钱；长期低于约 300 元/吨，倾向减产检修
开工率 / 库存装置负荷、社会库存天数判断后面供应松紧，比单日涨跌有用
MEG大商所（DCE）EG 合约，另一项主原料必须和 PTA 成对看，只盯一项会误判

合约代码与交易单位为交易所公开信息；加工费公式、300 元/吨松紧线为行业通行口径（经验值），各机构测算略有差异。

两条链，别混着谈（本节最该记住的一张表）
面料原料路线报价盯什么
涤纶石脑油 → PX → PTA ＋ MEG → PET → 涤纶丝PTA、MEG、涤纶 POY/FDY
锦纶苯 → 环己酮 → 己内酰胺（CPL） → PA6 → 锦纶丝CPL、纯苯、锦纶 POY/FDY

我们做的 15D34F 是无光锦纶（尼龙 6），成本落在己内酰胺和纯苯上，跟 PTA 没有直接关系。客户拿涤纶行情来压锦纶的价，前提就错了。

7.5.1 PTA 涨 100 元，布价到底涨多少（算给客户听）

这是最能立刻用上的一段。以常规涤塔夫为例，假设 100 克/㎡、门幅 1.5 米：

算一遍 PTA 涨 100 元/吨 → 切片成本涨 0.855 × 100 ≈ 85.5 元/吨
一米布用丝 ＝ 1.5 ㎡ × 100 克 ＝ 0.15 kg
丝价涨 85.5 元/吨 ＝ 0.0855 元/kg → 每米只涨 0.15 × 0.0855 ≈ 0.013 元
// 结论：PTA 涨 100，一米布涨一分多——涨的是吨价，不是米价

上述为理论换算（经验值），未计纺丝加工费、织造损耗与染整；实际报价以丝厂、织厂当日报价为准。算例的价值不在精确，而在让客户知道「盘面涨 100」和「布价涨多少」不是一个量级。

三个最容易犯的错

① 把 PTA 说成「检测指标」——它是原料，标准里没有这一项，张口就说会掉分。
② 拿涤纶涨跌解释锦纶报价——两条链节奏不同，有时反向。
③ 只看 PTA 不看 MEG——切片成本由两项共同决定。

对客话术（可直接照说）

客户：「涤纶都跌了，你这尼龙怎么还这个价？」
答：「涤纶看 PTA，锦纶看己内酰胺，这是两条产业链，价格不联动。我们这块是尼龙 6，成本在己内酰胺上。」

客户：「PTA 跌了，你们涤纶面料该降了吧？」
答：「PTA 涨跌 100 元，一米布也就动一分多，真正决定布价的是丝价、织造和染整。我们买的是纺好的丝，短期跟丝价，不跟盘面。」

一句话带走

PTA 是涤纶的原料、不是检测项；涤纶看 PTA 和 MEG，锦纶看己内酰胺和纯苯；盘面涨 100 元，一米布只动一分钱。
