客户发来一张物性卡写着 25%AC 75%P，你得三秒读出来，还得知道它不合规在哪

字母不是国际强制代号，各家卡面写法不统一：A 有的厂指腈纶、有的指羊毛；T 多数指涤纶，也有厂当纱支用。见到生面孔，以卡面中文为准，别硬猜。

二、常见组合怎么念

25AC / 75P
腈纶 25%，涤纶 75%
仿毛、里布；做防绒胆布不行——没有高密压光
90N / 10SP
锦纶 90%，氨纶 10%
四面弹、轻薄羽绒外层
65T / 35C
涤纶 65%，棉 35%
工装、衬衫，俗称 TC
65C / 35T
棉 65%，涤纶 35%
贴身款，俗称 CVC，比 TC 舒服
100P
纯涤纶
摇粒绒、里布、低价外层
50W / 50AC
羊毛 50%，腈纶 50%
仿呢料大衣，降成本不降手感

三、别把工艺参数当成成分

75D / 40S / 32S：旦数（D）和纱支（S），说的是纱线粗细，不是成分。
DTY / FDY / FTY / POY：长丝的加工方式，也不是成分。
CD：阳离子可染涤纶，是涤纶的一种；T400：双组分弹性丝，也不是“另一种纤维”。
20D / 15D：旦数，越小数越细；34F：一根丝里 34 孔，影响手感不是成分。

客户说“这是 75D 的布”，只说明纱细，含量还得看成分那行。

四、这种写法为什么不合规

标 “25%AC 75%P” 出现在商品标签上会被挑出来，两处硬伤：
① 顺序反了：应按含量从大到小排；
② 用了英文缩写：必须写规范中文名，缩写只能补充。
  • 依据：GB/T 29862《纺织品 纤维含量的标识》——纤维名称用规范名称，含量按递减顺序标注。
  • 正确写法：聚酯纤维 75%，腈纶 25%。
  • 允差：混纺一般 ±5 个百分点；含量 ≤10% 的组分 ±3 个百分点。具体以检测机构判定为准。
  • 标 100%：意味着不含其他纤维，检出别的纤维即判不符——这类争议直接送检，别口头解释。
  • 厂内物性卡用缩写没问题，商品吊牌 / 洗标必须按上面写。

五、看成分猜用途（羽绒服这行）

N 或 P 为主、35–60 g/㎡、压光/轧光 → 防绒胆布。掺 AC 会掉密度，别当胆布卖。
P 为主 + R 或 AC 少量、60–90 g/㎡ → 里布、内袋。
P 100% 或 P/AC、200–300 g/㎡ → 摇粒绒、领口、内胆贴片。
N 85–95% + SP 5–15% → 四面弹外层，做轻薄羽绒有弹。
AC 50% 以上 → 仿毛、呢料，秋冬款外层，不是防绒料。

一句话对客户说：“这卡上写的 25AC 75P，是腈纶两成半、涤纶七成半；做里布行，做防绒胆布不行。”
