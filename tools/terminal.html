终端入门 · 从打开到第一次对话

五分钟上手　·　照着做就行　·　dv面料手记 · 工具

第 1 步

打开「终端」

Mac 自带，不用装。两种办法任选：

A（最快）按 ⌘ + 空格，输入「终端」，回车。

B访达 → 应用程序 → 实用工具 → 终端。

打开后是一个窗口，里面一行字，末尾是 % 或 $。那是“等着你下命令”的地方，不是报错。
第 2 步

进到要干活的目录

输入下面这行，回车。站点想改就进站点目录，资料想改就进资料目录。

cd ~/deploy-fabric-book

资料库：

cd ~/Documents/面料资料
cd 是“进去哪个文件夹”。~ 代表你的用户目录，不用改成别的。
第 3 步

启动对话

codex

回车后屏幕变成 Codex 界面，底部等你打字。第一次会问是否信任这个目录，选 Yes / Trust，只问一次。

第 4 步

像微信一样说话

直接打中文，回车发送。第一次可以这样问：

这个仓库有哪些页面？只回答，不要改任何文件

它回完可以接着问，上下文会接着。想让它动手时，指令里说清三件事：哪个文件、改哪一句、其它不动。

第 5 步

退出

/quit

或者按 Ctrl + D，或者直接关窗口。

三个常见情况

现象怎么办
打字出来是英文标点、中文打不出按 Ctrl + 空格 切输入法
报 command not found: codex先输 source ~/.zshrc 回车，再输 codex
问「是否信任此目录」选 Yes / Trust，只问一次

两个常用小命令（会这俩就够）

看当前在哪个目录（忘了自己在哪儿时）：

pwd

看这个目录里有什么：

ls
不需要记更多。真正的活在 Codex 里说中文就行，终端只负责“进去、启动、退出”这三下。

一句话记住全流程

⌘空格 → 输「终端」→ 回车 → 输 cd ~/deploy-fabric-book → 回车 → 输 codex → 回车 → 开始打字
